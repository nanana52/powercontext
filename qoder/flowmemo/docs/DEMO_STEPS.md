# DEMO_STEPS — FlowMemo 演示步骤

线上地址：<https://flowmemo-workspace-7u2qbfllad4.qoder.zone/>（公开访问，无需登录）

> 演示前先确认顶部徽章：绿色「已连接」表示 PowerContext 可用，可完整演示记忆（2026-11-03 线上实测即为该状态）。若徽章显示红色「未连接」，页面会给出真实错误类别（如 `PowerContext 返回非 JSON 响应（HTTP 404，Content-Type=未知）` 表示上游实例或端口可见性有问题），此时记忆步骤改走文末「断线演示」，基础功能仍可完整演示。

## 演示主线（约 5 分钟）

### 步骤 1：导入演示数据
1. 打开首页，确认顶栏徽章与「长期记忆」状态文本已给出明确结论（不会停在「检测中…」）
2. 点击顶栏「载入演示」
3. KPI 卡片更新为：记录数 2、待办数 4、已完成 0、风险数 2
4. 左栏出现两条虚构会议记录（周会纪要 2026-10-28 / 2026-10-30）
5. 中栏出现 4 个待办、2 条决策、2 条风险
6. 重复点击「载入演示」→ 提示「已导入 0 条演示记录」，不产生重复数据

### 步骤 2：完成任务并验证持久化
1. 点击第一个待办左侧圆点 → 该项变删除线灰色，KPI「已完成」0 → 1
2. **按 F5 刷新页面**
3. 确认 2 条记录、4 个待办、勾选状态与统计卡片全部保留（浏览器 localStorage）

### 步骤 3：保存长期记忆（需 PowerContext 已连接）
1. 滚动到底部「长期记忆 (PowerContext)」卡片
2. 在输入框输入：`周报先写已完成事项，再写风险`
3. 点击「保存偏好」
4. 观察：输入框被清空 + 提示「偏好已保存到 PowerContext」
5. 若保存失败，输入框内容**保留**，并显示真实错误，诊断日志同步记录状态码
6. 展开「▸ 核验证据」，确认记录了 `request_id`

### 步骤 4：刷新后召回记忆并生成周报
1. **刷新页面**（模拟重新打开网站）
2. 点击「召回记忆」→ 输入框被真实偏好文本填充，提示「已从 PowerContext 召回偏好」
3. 点击右侧「生成周报」
4. 观察周报：
   - 头部标注「PowerContext 记忆偏好已应用」（而不是默认的「使用默认章节顺序」）
   - **`## 已完成` 出现在 `## 风险` 之前** —— 与步骤 3 保存的顺序一致
   - 「已完成」只列出真正勾选完成的任务，不编造
   - 未提及的章节（进行中/待办、决策、下周计划）保留在末尾，信息不丢失

### 步骤 5：验证记忆真实改变了结构
1. 把偏好改为相反顺序：`周报先写风险，再写已完成事项`，点击「保存偏好」
2. 再次点击「生成周报」
3. 观察 **`## 风险` 现在排在 `## 已完成` 之前** —— 同一份数据，章节顺序随记忆变化
4. 展开「▸ 核验证据」，确认 `source=search` 或 `source=entries`、`count` 命中数与 `request_id`

### 步骤 6：复制与下载
1. 点击「复制」→ 剪贴板内容为 Markdown 原文
2. 点击「下载 MD」→ 得到 `周报_YYYY-MM-DD.md`

## 访客隔离演示（对应第 8 项）

1. 完成访客 A 的保存（步骤 3）
2. 打开无痕窗口访问同一站点 → 服务端为其签发新的访客身份与新 Scope
3. 在无痕窗口点击「召回记忆」→ 提示「未找到已保存的偏好」，**不会**读出访客 A 的内容
4. 也可用脚本一次性验证：`python qa/live_acceptance.py`（含异会话读取、跨项目 token 复用、外部 `scope_id` 注入三类用例）

## 断线演示

1. 停止 PowerContext 服务（或让 Codespace 超时）
2. 刷新页面
3. 顶栏徽章显示「未连接」，长期记忆区显示真实错误来源（未配置 / 不可达 / 上游 HTTP 状态码）
4. 保存与召回均给出明确失败原因且保留用户输入，绝不伪造成功
5. 基础功能（载入演示、勾选完成、刷新持久化、生成/复制/下载周报）仍完全可用

## 页面内诊断日志说明

底部的「诊断日志」是为排查线上问题而加的临时区域，只输出脱敏信息：时间、级别、API 路径与 HTTP 状态码、`request_id`、命中数量、错误类型。不输出 Token、Secret 值或完整 sessionId。若评审希望关闭，删除 `dist/index.html` 中的 `diagnostic-section` 区块与 `app.js` 的 `addDiagnostic/renderDiagnostics` 即可，不影响功能。
